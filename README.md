# ArrowBuddies

A premium, child-friendly arrow-puzzle game built 100% in Kotlin with Jetpack Compose for Android.

## About the Game
Cute animal buddies are trapped in a maze. Each buddy faces one direction, shown by an arrow badge.
Tap a buddy and it dashes that way. Clear path to the edge = it escapes and is RESCUED!
Find the right order to free everyone and build your Sanctuary.

- **Stack**: 100% Kotlin, Jetpack Compose, Material 3, Navigation Compose, Dagger Hilt, Room, DataStore Preferences
- **Architecture**: Pure Kotlin Engine (:engine) + Android App (:app) with Unidirectional Data Flow (UDF)
- **Design**: Clay/soft-toy procedural vector graphics, zero bitmaps, fixed bright palette
- **Target**: Android 8.0+ (minSdk 26, compile/targetSdk 35), offline-first, child-safe (no ads/energy/IAP)
